# M2-03 · SQLite repositories with FTS5 over metadata and derived data

**Draft ID:** M2-03 · **Labels:** `type:feature` `area:core` `p0` · **Size:** L · **Blocked by:** M2-01, M2-02 · **Packages:** packages/db · **SENSITIVE**

**Read first:** docs/brief.md §5.3 › Storage performance, §5.10; docs/adr/0005-local-storage.md, docs/adr/0009-store-metadata-not-mail.md; `packages/core/src/ports/repositories.ts`; contract suites in `packages/testing/src/*-contract.ts`

**Context**
All repositories on SQLite, with the indexes and incremental sender stats the Overview needs at 100k+ messages.

**Scope**
- Adapters for accounts, messages, threads, senders, derived, signals, suggestions, action log (append-only), topics, cursors, digest state; every method workspace-scoped.
- Indexes for every list/filter query (account+category, sender, date); sender stats maintained in the same transaction as message upserts.
- FTS5 table over sender, subject, snippet, category and signals only; kept in sync by triggers or in the same transaction. Never body text (ADR 0009).
- Schema has no column that could hold a body or an attachment; saved documents belong to the blob store (M6).

**Acceptance criteria**
- [ ] Every SQLite repository passes its exported M1 contract suite unchanged (repositories, entity, derived, insight, signal, digest-state, sync contracts).
- [ ] Schema test: no table or column named or typed to hold message bodies or attachment bytes (named D11 guard).
- [ ] Sender stats equal a full recount after a mixed upsert/replay sequence (named test).
- [ ] 100k synthetic messages: indexed top-50 and sender GROUP BY stay under budgets recorded in the PR (order of ADR 0005 numbers); FTS5 query finds by subject, never by body text.
- [ ] Account removal deletes that account's rows and nothing else (named test).
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Blob store (M6), embeddings storage (M3).
