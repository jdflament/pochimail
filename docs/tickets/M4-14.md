**Context**
Home usable from the first second: status strip, Catch what matters, Clean up, all updating from events.

**Scope**
- Status strip bound to `ScanProgressed` (percentage, latest action, Pause/Resume, View summary); serif Overview title.
- Catch what matters (people waiting, deadlines, important people; 'I never clean these'; Review) and Clean up (headline figure, storage bar, recommendations ordered by impact, closing never-cleaned line) from queries kept fresh by events.
- Review opens a placeholder detail (E5 builds it); nothing runs from this screen.
- Numbers match the mock dataset on the fixture (48,312 emails, 6.4 GB, 3.1 GB freeable, 7 people waiting, 3 deadlines, 12 important).

**Acceptance criteria**
- [ ] Events change the figures without refetch or flicker (named test with a scripted event stream).
- [ ] Pause stops progress and Resume continues from the same point (named test over the real IPC layer).
- [ ] Fixture numbers equal the brief's mock dataset (named golden test).
- [ ] Empty accounts show the 'nothing to do' or empty state, not zeros in a ledger.
- [ ] Usable at 960, 860 and phone width (checked in M4-19 visual tests).
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Review/detail screens, real classification (M3).
