# M2-09 · Gmail provider: history sync and batch modify

**Draft ID:** M2-09 · **Labels:** `type:feature` `area:mail` `p0` · **Size:** L · **Blocked by:** M2-05, M2-07, M2-08 · **Packages:** packages/mail · **SENSITIVE**

**Read first:** docs/adr/0004-incremental-sync-and-imap.md (Gmail row, quotas, history expiry); docs/adr/0007-oauth-credentials-scopes.md (scopes); docs/brief.md §5.3, §4; docs/adr/0009-store-metadata-not-mail.md; `packages/core/src/ports/mail-provider.ts`

**Context**
First real `MailProvider`: Gmail via the API, headers first.

**Scope**
- `sync` backfill newest → oldest with `messages.list` + metadata gets (batched, quota-aware), then `history.list` deltas; stale `historyId` (404) → full re-list with `restarted: true`.
- Maps to `IncomingMessage` with headers/metadata and a snippet capped at `MAX_SNIPPET_CHARS`; `List-Unsubscribe` headers kept; no body fetched during sync (D11).
- `applyCommands` via `batchModify` (≤1000 ids, remove `INBOX` to archive, label add/remove) returning the inverse for each command.
- `fetchBody` on demand, in memory only.
- Capabilities: labels, `remove-inbox-label`, batch 1000, delta true, push false, unsubscribeSend false.

**Acceptance criteria**
- [ ] Passes the exported `mail-provider-contract` and `sync-contract` unchanged, running against the recorded fixtures (M2-08).
- [ ] Expired `historyId` triggers a full re-list with `restarted: true`, final state equals a clean backfill (named test).
- [ ] No request fetches a message body or attachment during `sync` (named D11 test asserting the requested fields).
- [ ] 429 → core `RateLimited` with the right delay; 401 → `AuthExpired`.
- [ ] Archive then the returned inverse restores `INBOX` (named test).
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: IDLE (opt-in, M2-16), send scope, real-account smoke test (manual, tracked in PR).
