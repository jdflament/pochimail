# M4-02 · worker composition root and model host process (fixture-backed)

**Draft ID:** M4-02 · **Labels:** `type:feature` `area:desktop` `p0` · **Size:** L · **Blocked by:** M4-01, M1-14 (merged by then) · **Packages:** apps/desktop, packages/core, packages/testing · **SENSITIVE**

**Read first:** docs/adr/0002-electron-process-model-and-ipc.md (process model, model host); docs/adr/0003-hexagonal-core-events-outbox.md; docs/brief.md §5.4, §6 › Mock data; `apps/desktop/src/worker/worker.ts`

**Context**
The worker becomes the composition root so M4 screens run against the fixture mailbox with no real account, and M2 adapters swap in later through the same ports.

**Scope**
- Composition root: core use cases + in-memory/fixture adapters (`FixtureMailProvider`, in-memory store) behind a single `createWorkerApp(adapters)`; M2's SQLite/real adapters plug in without touching handlers.
- Implements the M4-01 handlers (accounts, scan start/pause/resume, overview numbers, digest, settings); streams domain events.
- Second `utilityProcess` for the model host: spawn, health, restart on crash, talks to the worker via a port; no model inside yet (stub `LlmProvider`/`Embedder` from the fake adapters).
- Demo mode flag selecting fixtures: how `packages/testing` ships in a packaged build is an open question for JD; until answered it is dev/E2E only.

**Acceptance criteria**
- [ ] Starting a scan on the fixture streams `ScanProgressed` to the renderer and ends with `ScanCompleted` and `DigestReady` (named test over the real IPC layer).
- [ ] Killing the model host does not take the worker down; it restarts and the scan continues (named test).
- [ ] Handlers contain no business logic: they call core use cases only (lint/arch test).
- [ ] Swapping the adapter bundle (fixture → a second fake) needs no handler change (named test).
- [ ] The overview numbers for the fixture match the mock dataset (brief §6).
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Real accounts and SQLite (M2), real models (M3).
