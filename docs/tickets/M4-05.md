**Context**
A plain sheet from Pochi over the current screen, never a page, built on the existing Dialog/Sheet primitives.

**Scope**
- Summary content: small Pochi icon + 'From Pochi · date', serif title, one sentence, three figures, one next step with primary action + Later, Keep it tidy pill choices.
- Sheet container with scrim: standard sheet enter (scrim fade + slide, ~250ms, one easing); desktop sheet, below 560px becomes a bottom sheet; closes with ×, Later and Esc; focus trapped and restored.
- Content via props so Autopilot/weekly variants (M5/M7) reuse it.

**Acceptance criteria**
- [ ] Esc, × and Later each close it and return focus to the opener (named tests).
- [ ] Below 560px the same component renders as a bottom sheet (container-query story + test).
- [ ] Dialog semantics: labelled, focus trap, scroll lock (a11y check passes).
- [ ] Stories in light and dark and phone width; no hard-coded colors.
- [ ] Shows only the supplied 'new' figures; no totals computed inside the component.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Wiring to digest events (M4-15), motion timings (M4-17).
