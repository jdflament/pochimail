# M4-19 · Playwright: onboarding smoke and light/dark visual tests

**Draft ID:** M4-19 · **Labels:** `type:feature` `area:infra` `p0` · **Size:** L · **Blocked by:** M4-15, M4-18 · **Packages:** apps/desktop, tooling

**Read first:** docs/brief.md §8 › Testing (Playwright smoke: onboarding, background sorting, action + undo), §6 States and motion; docs/adr/0002 (hardening, Fuses); `apps/desktop/packaging/smoke.ts`

**Context**
No Playwright exists yet. Add it with Electron support, running against the fixture-backed worker (no real account).

**Scope**
- Smoke: Welcome → Connect (fixture account) → Setup → Overview while sorting (numbers move) → Summary sheet → close; background sorting pause/resume.
- Visual tests in light and dark for every screen and every state in the gallery; baselines committed, tolerance documented; runs on CI with a 3-OS decision recorded (visuals on one OS if fonts differ).
- Action + undo smoke is added when M5 lands; leave the hook.

**Acceptance criteria**
- [ ] Smoke passes on macOS, Windows, Linux CI and fails if a screen throws (named test).
- [ ] A one-pixel token change in a state fails the visual diff (demonstrated once in the PR).
- [ ] Playwright and its browsers are pinned and respect `minimumReleaseAge`; CI time impact reported.
- [ ] Test harness cannot enable Node in the renderer (hardening test still passes).
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Action+undo scenario (M5), real providers.
