# M4-05 · packages/ui: responsive Sheet primitive (centred sheet on desktop, bottom sheet on phones)

**Draft ID:** M4-05 · **Labels:** `type:feature` `area:ui` `p0` · **Size:** M · **Blocked by:** M0-07, M0-08 (merged), M4-04 · **Packages:** packages/ui

**Read first:** docs/design.md › Components, Motion; docs/brief.md §6 (Style, Interaction and accessibility rules, Anti-patterns); docs/design/screens/html/; docs/design.md (Summaries, Motion). Already in `packages/ui` (M0-07/08): button, switch, checkbox, radio-group, dropdown-menu, dialog, tooltip, sonner, skeleton, separator, scroll-area, `Mascot` (pose prop, 5 PNG poses), tokens + contrast test, Storybook with a11y addon. Do not re-add them.

**Context**
One reusable, plain sheet primitive over the current screen, never a page, on standard Dialog semantics (shadcn Sheet/Drawer-style composition). It carries no summary content, no paper look and no decoration; the summary itself (title, sentence, three figures, next step, Keep it tidy) is composed from plain primitives later in the feature by M4-15.

**Scope**
- `packages/ui/components/sheet`: `Sheet`, `SheetTrigger`, `SheetContent`, `SheetHeader`, `SheetTitle`, `SheetDescription`, `SheetFooter`, `SheetClose` (shadcn conventions: React 19 function components, CVA, `data-slot`, `asChild`, `focus-visible`, composition over boolean props). The × button is built into `SheetContent` and labelled from the catalog (`action.close`, en/fr/ja).
- Centred sheet over the current screen; below 560px of its own container it becomes a bottom sheet, same markup (container query on the sheet's layer).
- Motion: scrim fade + slide, ~250ms, one easing (`cubic-bezier(0.22, 1, 0.36, 1)`); reduced motion respected.
- Dialog semantics from Radix: labelled by title and sentence, focus trapped and restored to the opener, scroll lock, Esc closes.
- One Storybook story composes a summary with plain primitives (desktop and 390px frame) to prove the sheet fits it.

**Acceptance criteria**
- [ ] Esc, × and a `SheetClose` action each close it and return focus to the opener (named tests).
- [ ] Focus is trapped inside the open sheet (named test).
- [ ] Below 560px the same markup renders as a bottom sheet (container-width test + phone story).
- [ ] Dialog semantics: labelled, focus trap, scroll lock (a11y check passes).
- [ ] No hard-coded colors; no new strings outside the catalog.
- [ ] Test bar: behaviour tests through public entry points only; each test guarding a named failure.

**Out of scope**: the summary composition and wiring to digest events (M4-15), motion timings (M4-17), any summary-specific component.
