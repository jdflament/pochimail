# Security policy

Pochimail handles people's entire mailbox, so we treat security as a feature.

## Reporting a vulnerability
Please **do not open a public issue**. Use GitHub private vulnerability reporting:
**Security tab → "Report a vulnerability"** on the repository's [Security tab](../../security/advisories/new).

Include what you found, how to reproduce it, the version and your operating system. Never include real email content or credentials.

You can expect an acknowledgement within 7 days and a status update at least every 14 days until it is resolved. We credit reporters who want it. Please give us reasonable time to fix before disclosing.

## Scope
In scope: the Pochimail desktop app, its build and update pipeline, and handling of OAuth tokens, app passwords and mailbox data. Out of scope: vulnerabilities in the mail providers themselves, and attacks requiring full control of an unlocked device.

## Supported versions
Only the latest stable release receives security fixes. There is no release yet.

A dedicated disclosure address and an external security review are planned before 1.0.
