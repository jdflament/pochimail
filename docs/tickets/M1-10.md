# M1-10 · fixture mailbox:.mbox generator + FixtureMailProvider

**Draft ID:** M1-10 · **Labels:** `type:feature` `area:core` `p0` · **Size:** L · **Blocked by:** M1-03 · **Packages:** packages/testing, fixtures/

**Read first:** docs/brief.md §6 › Mock data, §3, §8 › Testing

**Context**
A deterministic, realistic mailbox with ground-truth labels powers the CLI demo, the eval harness and every later milestone's tests.

**Scope**
- Seeded generator producing.mbox files reproducing the mock dataset proportions: 2 accounts, 7 categories, signals, documents; small and full scale.
- EN/FR/JA samples including encodings and long threads.
- Ground-truth labels file (category, signals, expected suggestions) alongside the mbox.
- `FixtureMailProvider` implementing `MailProvider` over the generated mbox, incl. delta cursors and archive/label effects in memory.
- No real personal mail anywhere in the repo.

**Acceptance criteria**
- [ ] Same seed produces byte-identical output (named determinism test).
- [ ] Generated proportions match the mock dataset numbers in brief §6 within stated tolerance.
- [ ] FixtureMailProvider passes the `MailProvider` contract suite from M1-09.
- [ ] Every generated message has a ground-truth label; labels file validates against its schema.
- [ ] Small fixture generates in under a few seconds on CI.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Real-world corpora and training data (M3, P12).
