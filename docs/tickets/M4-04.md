**Context**
The choice and feedback pieces of Welcome, Setup, the states and the undo flow.

**Scope**
- Speech bubble (Mascot beside it), Checkbox card, Radio card (Suggest 'recommended' variant), Pill radio group (Keep it tidy cadence), sonner toast + action (built on sonner, dark, 5s), Empty/error state (mascot pose + title + one primary action).
- Same conventions as M4-03; built on the existing checkbox and radio-group primitives.

**Acceptance criteria**
- [ ] Stories in light and dark for every variant; a11y check passes.
- [ ] Radio/checkbox cards are operable by keyboard and announce checked state (behaviour tests with role queries).
- [ ] Undo toast action fires once and auto-dismisses after 5s (fake timers).
- [ ] Empty/error state always renders exactly one primary action (named test).
- [ ] No hard-coded colors, contrast test green.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Required-state screens and copy (M4-16), motion (M4-17).
