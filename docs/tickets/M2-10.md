# M2-10 · Microsoft Graph provider: delta sync and $batch

**Draft ID:** M2-10 · **Labels:** `type:feature` `area:mail` `p0` · **Size:** L · **Blocked by:** M2-05, M2-07, M2-08 · **Packages:** packages/mail · **SENSITIVE**

**Read first:** docs/adr/0004-incremental-sync-and-imap.md (Microsoft row, Graph limits); docs/adr/0007-oauth-credentials-scopes.md; docs/security/oauth-verification.md (Graph notes); docs/brief.md §5.3; `packages/core/src/ports/mail-provider.ts`

**Context**
Second `MailProvider`: Graph `/messages/delta`, headers only.

**Scope**
- `sync` with one delta token per folder (`SyncCursor.scope`), `$select` limited to metadata fields (no `body`), follow `@odata.nextLink`/`deltaLink`; token expiry or `syncStateNotFound` → full walk with `restarted: true`.
- `applyCommands` via `$batch` (≤20 per call): move to Archive folder, Outlook categories, inverses recorded.
- Personal Outlook.com and work/school accounts both supported (multitenant registration in ADR 0007).
- Capabilities: folders, `move-to-archive-folder`, batch 20, delta true.

**Acceptance criteria**
- [ ] Passes `mail-provider-contract` and `sync-contract` unchanged against recorded fixtures.
- [ ] Expired delta token falls back to a full walk, same final state (named test).
- [ ] `$select` never includes `body`/`attachments` (named D11 test).
- [ ] `$batch` item-level 429 is retried per item and a persistent one surfaces `RateLimited` (named test).
- [ ] Archive move then inverse returns the message to the Inbox (named test).
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Graph IDLE opt-in, `Mail.Send`, publisher verification (M2-19).
