# M4-13 · Setup screen: capabilities and autonomy

**Draft ID:** M4-13 · **Labels:** `type:feature` `area:desktop` `p0` · **Size:** S · **Blocked by:** M4-04, M4-10, M4-02 · **Packages:** apps/desktop

**Read first:** docs/brief.md §2 (Questions 1-2), §7 item 3; docs/plan.md D9, D10; docs/design/screens/html/Mode.html, light/03-setup.png

**Context**
Two plain questions, one button: Start sorting.

**Scope**
- Speech bubble, capabilities as checkbox cards (all on, Catch what matters first), autonomy as radio cards (Suggest recommended; Just look / Suggest / Autopilot), invariants reminder, 'Start sorting' → `settings.save` + `scan.start`.
- Light desktop is canonical; ignore the dark/phone export glitches (P7).

**Acceptance criteria**
- [ ] Defaults match the brief (all capabilities on, Suggest selected); the choice is saved and read back (named test).
- [ ] Start sorting starts the scan and navigates to Overview while it runs.
- [ ] Choosing Autopilot shows the extra reminder copy (D9/D10 wording from the catalog).
- [ ] Keyboard operable; no numbered headings.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Re-prompting for broader scopes when autonomy rises (M2-05, M7 settings).
