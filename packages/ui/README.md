# @pochimail/ui

Design system for Pochimail: tokens, fonts, brand and mascot assets, shadcn/ui components (`src/components`, added with `pnpm ui:add` from `apps/desktop`).

- `src/styles/`: `tokens.json` (source), `tokens.css`, `theme.css`, `globals.css`.
- `src/fonts/`: self-hosted woff2 + OFL licenses (no runtime font requests).
- `src/assets/brand/`, `src/assets/mascot/`: CC BY-NC-ND 4.0, see each `LICENSE` and `/TRADEMARKS.md`.
