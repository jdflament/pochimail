# M4-18 · dev-only gallery route for states and motion

**Draft ID:** M4-18 · **Labels:** `type:feature` `area:desktop` `p0` · **Size:** S · **Blocked by:** M4-16, M4-17 · **Packages:** apps/desktop

**Read first:** docs/brief.md §6 › States and motion are features; docs/adr/0002-electron-process-model-and-ipc.md (hardening); Storybook config in packages/ui/.storybook

**Context**
Review and test every state and motion in isolation inside the real app shell (Storybook already covers components).

**Scope**
- `/gallery` route present only in dev and E2E builds (excluded from packaged production), listing every state and motion with light/dark and reduced-motion toggles.
- Entries import the same stories/components, no copies.

**Acceptance criteria**
- [ ] The route is absent from the packaged build (packaging smoke check, named test).
- [ ] Every state from M4-16 and every moment from M4-17 is listed (test compares to the catalogs).
- [ ] Toggling theme and reduced motion changes the rendering.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Visual regression (M4-19).
