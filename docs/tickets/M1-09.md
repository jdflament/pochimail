# M1-09 · packages/testing: in-memory adapters for all ports + port contract suites

**Draft ID:** M1-09 · **Labels:** `type:feature` `area:core` `p0` · **Size:** L · **Blocked by:** M1-03 · **Packages:** packages/testing

**Read first:** docs/brief.md §8 › Testing; docs/adr/0003-hexagonal-core-events-outbox.md

**Context**
One set of fakes lets every milestone test against the same behaviour, and the contract suites keep real adapters honest.

**Scope**
- In-memory implementation of every port from M1-03 (repositories, BlobStore, SecretStore, JobQueue, EventBus, Scheduler, Notifier, PowerMonitor, Platform, fake Classifier/Embedder/LlmProvider, fake Clock).
- Contract suites per port, exported as functions that take an adapter factory.
- Controllable fakes (advance clock, force failure, simulate offline/rate-limit).

**Acceptance criteria**
- [ ] Each in-memory adapter passes its own contract suite in CI.
- [ ] A deliberately broken adapter (e.g. repository that loses writes on rollback) fails the suite (named mutation test).
- [ ] Contract suites import only from public entry points and can be run from another package (verified by a tiny consumer test).
- [ ] Fakes can simulate `RateLimited` and `Offline` errors on demand.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: SQLite/real provider adapters (M2).
