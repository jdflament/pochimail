# M4-06 · Mascot behaviours: Show Pochi, Animations, reduced motion, idle and found reactions

**Draft ID:** M4-06 · **Labels:** `type:feature` `area:ui` `p0` · **Size:** S · **Blocked by:** M0-07 (merged) · **Packages:** packages/ui

**Read first:** docs/mascot.md; docs/design/screens/source/Motion.dc.html (timings = source of truth, plan P5); docs/design.md › Motion catalog; docs/brief.md §6 › Mascot; `packages/ui/src/components/mascot.tsx`

**Context**
The `Mascot` component renders poses; this adds the behaviour and the user preferences around it.

**Scope**
- Idle breathing and blink loops, 'finds something' squish-bounce, using the Motion.dc.html timings exactly (breathing 4.2s, blink 5.3s, found 620ms).
- Preferences as props/context: Show Pochi (off hides all mascot), Animations (off holds still), `prefers-reduced-motion` forces still.
- Pose set limited to the five PNGs that exist; missing poses are not invented.

**Acceptance criteria**
- [ ] With reduced motion or Animations off, no animation runs and the mascot holds still (named tests).
- [ ] Show Pochi off renders no mascot and leaves layout intact (named test).
- [ ] Timings equal the Motion.dc.html values (test reading the constants).
- [ ] Stories for each pose and for each preference; a11y: mascot is decorative (`alt=""`) unless it carries meaning.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Rive (E8), new poses.
