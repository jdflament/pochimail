# @pochimail/gmail

## Why this package exists
Adapter package.
Gmail through the Gmail API, behind the accounts, mailbox, actions and documents ports.

## Owns
- History sync, header fetch, labels, archive, trash and restore, attachments, unsubscribe headers.

## May import
Domain packages (port types), `net`, `kernel`, `logger`, `zod`.

## Must not contain
- Graph code, storage, business rules.
