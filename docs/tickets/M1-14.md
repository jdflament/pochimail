# M1-14 · apps/cli: full pipeline on fixtures end to end

**Draft ID:** M1-14 · **Labels:** `type:feature` `area:core` `p0` · **Size:** M · **Blocked by:** M1-13, M1-11 · **Packages:** apps/cli

**Read first:** docs/brief.md §10 (M1), §6 › Mock data

**Context**
The M1 demo and integration test: proves the whole core works with nothing but in-memory adapters.

**Scope**
- `pnpm --filter cli pochi:run fixtures/mock` runs sync → classify → signals → suggestions → apply → undo in memory.
- Prints the mock-dataset summary (brief §6 › Mock data) and the eval precision/recall.
- CI runs the command as an integration test.

**Acceptance criteria**
- [ ] The command exits 0 and its summary matches the committed expected output (golden test).
- [ ] After the undo step the in-memory mailbox equals its pre-apply state (named test).
- [ ] Command fails (non-zero) if any pipeline stage reports an unhandled error.
- [ ] CLI contains only wiring: no business logic outside `packages/core`.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Real accounts and persistence (M2).
