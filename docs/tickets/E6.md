# Epic: M6 Documents

**Draft ID:** E6

**Goal:** Find, dedupe, browse and export the real documents in mail.

**Done when:** Real documents detected, deduped, browsable, exported with clean names.

**Planned children**
- [ ] Real-document detection (filter logos, inline images, tracking pixels)
- [ ] SHA-256 dedupe; saved attachments go to the user's own storage, not a Pochimail blob store ([ADR 0010](../adr/0010-saved-attachments-go-to-user-storage.md), Accepted 2026-11-19, supersedes the blob-store exception in ADR 0009). User chooses local or drive; Pochimail picks a starting folder and tidies it; naming is one setting (original names or smart naming / organize by date) with a sensible default.
- [ ] Document type classification (invoice, contract, ID, payslip…)
- [ ] Documents library (TanStack Table, filters, design draft P8)
- [ ] Export with clean naming (`2024/Invoices/Amazon_2024-03.pdf`) to the documents folder
- [ ] "Saving" Pochi pose events

**Read:** Brief §4 Documents, §5.3 Storage.

_Children become repo issues when the milestone starts. Source: docs/plan.md §2._
