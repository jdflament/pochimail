# M2-01 · SQLite core: encrypted database, migrator, UnitOfWork, outbox and job queue

**Draft ID:** M2-01 · **Labels:** `type:feature` `area:core` `p0` · **Size:** L · **Blocked by:** M1-03, M1-07 (merged) · **Packages:** packages/db · **SENSITIVE**

**Read first:** docs/brief.md §5.3 (outbox, storage performance), §5.10 › Data at rest; docs/adr/0005-local-storage.md, docs/adr/0009-store-metadata-not-mail.md; docs/adr/0003-hexagonal-core-events-outbox.md; `apps/desktop/src/worker/storage-proof.ts`, `apps/desktop/src/main/storage-key.ts` (M0-12 proof to productise)

**Context**
First real persistence. Turns the M0-12 proof into `packages/db`: one writer, encrypted WAL database, and the transactional pieces every later adapter builds on.

**Scope**
- Open `better-sqlite3-multiple-ciphers` (pinned as in ADR 0005) with a raw 256-bit key passed in by the caller (key source is M2-04); pragmas: WAL, `foreign_keys=ON`, tuned `cache_size`/`mmap_size`; wrong key → typed `StorageError`.
- Hand-written versioned `.sql` migrations + tiny migrator on `PRAGMA user_version` (no Drizzle, ADR 0005); migration 0001 holds the tables for outbox, job queue (leases, attempts, dead letter) and cursors.
- `UnitOfWork` adapter (reads outside, writes inside one transaction; rollback on error) and SQLite `Outbox` + `JobQueue` adapters.
- Row parsing with zod at the adapter boundary. D11: no bodies or attachments persisted (saved-document exception only); logs never contain subjects, addresses, snippets or tokens.

**Acceptance criteria**
- [ ] SQLite `UnitOfWork`, `Outbox` and `JobQueue` pass the exported M1 contract suites from `packages/testing` unchanged (unit-of-work, outbox, job-queue and job-queue-lease contracts).
- [ ] Domain writes and the events/jobs they produce commit together or not at all (named crash test: kill between write and relay, reopen, event still delivered once).
- [ ] Opening with a wrong key fails; the file header is not plain SQLite (named test).
- [ ] A migration run twice changes nothing; a newer `user_version` than the code knows refuses to open.
- [ ] The deliberately broken adapter from M1-09's mutation test, ported to SQLite (loses writes on rollback), fails the suite.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Repositories and FTS (M2-03), key storage (M2-04), worker wiring (M4-02).
