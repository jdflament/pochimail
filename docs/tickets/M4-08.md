# M4-08 · renderer shell: router, query-from-events, providers, theme

**Draft ID:** M4-08 · **Labels:** `type:feature` `area:desktop` `p0` · **Size:** L · **Blocked by:** M4-01, M4-07 · **Packages:** apps/desktop

**Read first:** docs/adr/0002-electron-process-model-and-ipc.md (Renderer data); docs/brief.md §5.4, §6 (Responsive layout), §8 › Frontend; `apps/desktop/src/renderer/src/router.tsx`, `lib/worker.ts`, `lib/theme.ts`

**Context**
App skeleton the screens plug into: routes, data layer, theme, window sizing.

**Scope**
- TanStack Router routes: welcome, connect, setup, overview, category, documents/activity/settings placeholders, dev gallery slot.
- Query-from-events: TanStack Query caches updated by subscriptions (no polling); optimistic mutation hooks reconciled on `ActionApplied`/`ActionFailed`.
- First-run vs returning-user redirect from `app.state`; theme follows system, `.dark` class; min window 720×560.
- Error boundary with the shared error state.

**Acceptance criteria**
- [ ] An event updates a cached query without a refetch (named test, fake IPC).
- [ ] First launch lands on Welcome; with a connected account lands on Overview (named test).
- [ ] A failed optimistic mutation rolls back on `ActionFailed` (named test).
- [ ] Strict CSP still holds (build test from M0-09); no Node access in renderer.
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Individual screens, sidebar layout (M4-09).
