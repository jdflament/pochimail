# M4-17 · motion catalog implementation

**Draft ID:** M4-17 · **Labels:** `type:feature` `area:ui` `p0` · **Size:** M · **Blocked by:** M4-03, M4-04, M4-05, M4-06 · **Packages:** packages/ui

**Read first:** docs/design/screens/source/Motion.dc.html (timings source of truth, P5); docs/design.md › Motion catalog; docs/brief.md §6 (Motion, Interaction rules); motion 14.14.0 already a dependency

**Context**
Build every row of the motion catalog once, reusable by screens.

**Scope**
- Live progress glide + finding slide-up, count-up (600ms), storage bar settle (700ms +140ms), row fold + undo toast (260/220ms), summary arrival with stamp overshoot, choice animations, screen-to-screen slide, panel fade/scale.
- Central timing constants copied from Motion.dc.html; CSS transitions where enough, `motion/react` for layout/presence.
- Every motion becomes an instant cross-fade under `prefers-reduced-motion` or Animations off.

**Acceptance criteria**
- [ ] A test fails if any timing constant differs from Motion.dc.html (named test).
- [ ] Reduced motion produces no transform animation (named test per primitive).
- [ ] No looping animation other than the mascot breathing (grep/test).
- [ ] Each moment has a story that replays it (feeds the gallery).
- [ ] Test bar: behaviour tests through public entry points only (no tests of private helpers); each test guards a named failure (its name states the bug it prevents); contract suites are exported so M2 adapters (SQLite, real providers) reuse them unchanged.

**Out of scope**: Looping or pulsing anything not in the catalog.
