# Repository URL: one source

The repository location lives in exactly one place: the `repository` field of the root `package.json`.
Everything that needs the owner or name (updater `publish` config, links in docs generated by scripts, About screen) must read it from there and never hard-code `pochimail/pochimail`.
The repo lives in the `pochimail` org (moved 2026-11-18); if it moves again, change that single field.
