# M0-09 · Electron skeleton with security baseline

**Draft ID:** M0-09 · **Labels:** `type:feature` `area:desktop` `p0` · **Size:** L · **Blocked by:** M0-02, M0-04

Read first: docs/brief.md §5.4, §5.9, §5.10 › Electron hardening, No network except; ADR 0002
**Scope**
electron-vite app with `src/main`, `src/preload`, `src/worker` (utilityProcess, echo RPC over MessagePort), `src/renderer` (React 19, TanStack Router root, React Compiler, `globals.css`); window min 720×560, OS-native chrome (traffic lights inset on macOS); hardening (contextIsolation, sandbox, no nodeIntegration, CSP, navigation/new-window blocking, permission handler deny-all, Fuses); session request filter with an allowlist (empty for now) logging blocked hosts; theme follows system with `.dark`.
**Acceptance criteria**
- [ ] `pnpm --filter desktop dev` opens a window showing "Overview" in Newsreader and body in Instrument Sans, correct in light and dark.
- [ ] Renderer ↔ worker echo round-trips over the MessagePort without passing through main handlers.
- [ ] Electronegativity (or equivalent checklist test) reports no high findings; a test asserts `window.open` and navigation to an external URL are blocked.
